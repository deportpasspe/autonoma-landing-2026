## Secciones (orden Figma)

1. Header — Cifras, Carreras, Modalidades, Testimonios, Campus
2. Hero — “Aquí no somos hijitos de papá” + form registro
3. Desafiar — lavanda + card amarilla + video
4. Cifras — 32% / 6/10 / 73% / 36%
5. Carreras — accordion “de algo grande”
6. Modalidades — Presencial / Semipresencial / Virtual
7. Propio camino — Accesibilidad / Flexibilidad / Trayectoria
8. Testimonios — María Fernández
9. Campus — Lima Sur / Lima Norte + footer contactos

## Responsive

- 375: stack, form debajo del hero, grids 1-col
- 768: stats 2-col, modalidades 1–3
- 1024+: layouts desktop del artboard 1440
